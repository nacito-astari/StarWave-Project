# StarWave: Fan Community & Merchandise App Design

A mobile app design for fans to follow artists, share community posts, and browse merchandise. This repository documents the UX planning, wireframes, and Figma interface.

## Project Overview

StarWave is an academic case study for fans aged 13–30 in Indonesia. The brief explores limited personal interaction with idols, difficulty finding reliable updates, and access to official merchandise. The design brings community content, artist posts, product browsing, and account management into one mobile interface.

Originally created as a first-semester group project, the interface was later refined for this portfolio with a blue-and-white palette and more consistent navigation styling.

The project focuses on UI/UX documentation and a Figma prototype.

## Main Features

The design covers onboarding, registration, sign-in, and five main menus:

| Menu | Designed Features |
| --- | --- |
| **Home** | Update banners, merchandise highlights, and newly joined artists. |
| **Interact** | Artist selection, community posts with image attachments, and likes on artist posts. |
| **Chat Bot** | An introductory screen and a chat interface for questions about StarWave and its artists. |
| **Shop** | Merchandise listings, product details, and a checkout flow for one item per order. |
| **Profile** | Personal information, profile editing, expandable FAQ answers, and About Us. |

## UX Design Process

- **User personas:** Two personas describing user goals, needs, and pain points.
- **User journey:** A map of activities, expected feelings, and opportunities for improvement within the case study.
- **Task flows:** Nine flows covering registration, reading posts, creating posts, reacting to artist content, chatbot questions, merchandise purchases, profile updates, FAQ, and About Us.
- **Wireframes and navigation map:** Screen layouts and relationships between the main menus and supporting screens.
- **Interface design:** Figma screens and components for navigation, tabs, forms, FAQ states, and confirmation pop-ups.

## Tools Used

- **Figma:** Wireframes, interface design, components, and prototyping.
- **Draw.io:** Navigation map.
